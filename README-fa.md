# شیرین‌یار 🍦
ماشین‌حساب صوتی فارسی برای بستنی‌فروشی و شیرینی‌فروشی؛ پیاده‌سازی اندروید با Kotlin، Android Speech Recognizer، TextToSpeech و Room.

## وضعیت و امکانات
- رابط فارسی و راست‌چین؛ فرمان صوتی با زبان `fa-IR` و امکان تایپ فرمان.
- محاسبه اقلام تعدادی و وزنی، قیمت دستی، تخفیف، جمع کل، حذف آخرین قلم و فاکتور جدید.
- ذخیره محصولات و فاکتور جاری در پایگاه‌داده محلی Room.
- قیمت‌های اولیه صرفاً برای راه‌اندازی نصب می‌شوند و قابل تغییرند. قبل از استفاده واقعی، قیمت‌ها را از داخل برنامه بازبینی کنید.
- وقتی نام محصول، مقدار یا مبلغ لازم مشخص نباشد، برنامه سؤال می‌پرسد و مبلغ را حدس نمی‌زند.

## نیازمندی‌ها
- Android Studio جدید با JDK 17
- Android SDK Platform 35
- دستگاه/شبیه‌ساز Android 8.0 (API 26) یا بالاتر
- برای گفتار، سرویس تشخیص گفتار نصب‌شده و پشتیبانی از فارسی لازم است. در برخی دستگاه‌ها تشخیص گفتار برای پردازش به اینترنت نیاز دارد.
- صدای فارسی TextToSpeech باید روی دستگاه موجود باشد؛ اگر نبود از تنظیمات سیستم، دادهٔ صدای فارسی را نصب کنید.

## اجرا
1. پوشه پروژه را در Android Studio با گزینه **Open** باز کنید.
2. اجازه دهید Gradle Sync انجام شود و SDKهای پیشنهادی نصب شوند.
3. دستگاه را وصل کنید یا شبیه‌ساز را اجرا کنید و Run را بزنید.
4. برای فرمان صوتی، اجازه میکروفون را تأیید کنید.
5. از «افزودن / تغییر قیمت محصول» نام و قیمت درست محصولات فروشگاه را ثبت کنید.

## فرمان‌های پشتیبانی‌شده
- «دو تا بستنی وانیلی» (اگر محصول در فهرست قیمت باشد)
- «نیم کیلو شیرینی تر»، «ربع کیلو شیرینی خشک»، «۲۵۰ گرم شیرینی تر»
- «چهل هزار تومن بذار روش» یا «ده هزار تومن تخفیف بده»
- «جمعش چقدر شد؟»، «آخرین مورد رو پاک کن»، «فاکتور جدید»

محدودیت عمدی: این نسخه parser محلی و شفاف دارد و مدل زبانی/پردازش ابری نیست. عبارت‌های پیچیده یا نامشخص باید با بازنویسی فرمان یا ثبت دقیق محصول حل شوند. اعداد گفتاری رایج مانند «چهل»، «ده» و «دویست» پشتیبانی می‌شوند. اگر واحد «هزار» یا «میلیون» گفته شود، ضریب اعمال می‌شود؛ برای جلوگیری از ابهام مبلغ را صریح بگویید، مثلاً «چهل هزار تومان».

## محاسبات و دقت
- واحد قیمت محصولات وزنی، تومان به‌ازای هر کیلو است؛ واحد محصول تعدادی، تومان به‌ازای هر عدد.
- مقادیر وزنی با دقت اعشاری محاسبه و مبلغ هر قلم به نزدیک‌ترین تومان گرد می‌شود.
- تخفیف بیش از جمع فعلی پذیرفته نمی‌شود.
- اطلاعات روی گوشی و در دیتابیس `shirinyar.db` ذخیره می‌شود؛ حذف برنامه ممکن است اطلاعات محلی را حذف کند.

## ساخت APK
در Android Studio از **Build > Build Bundle(s) / APK(s) > Build APK(s)** استفاده کنید. فایل خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` خواهد بود.

### ساخت خودکار با GitHub Actions
با push کردن پروژه به GitHub، workflow موجود در `.github/workflows/android.yml` فایل APK دیباگ را می‌سازد و به‌عنوان Artifact نگه می‌دارد. برای انتشار عمومی، امضای release و مدیریت امن کلید امضا را جداگانه تنظیم کنید.

## حریم خصوصی
برنامه حساب کاربری یا سرور اختصاصی ندارد. محصولات و اقلام فاکتور در پایگاه‌داده محلی ذخیره می‌شوند. تشخیص گفتار از سرویس Android استفاده می‌کند و نحوهٔ پردازش صدا به موتور گفتار انتخاب‌شده در دستگاه بستگی دارد.
